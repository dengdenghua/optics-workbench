# 两个 AI 入口

## Codex / MCP

按照 [MCP 文档](mcp.md) 把服务连到 Codex，与网页指定同一个配置和数据库。告诉 Codex 当前原型 ID 和指令，例如：读取当前场景，把准直透镜焦距改为 20 mm，检查孔径截光，再按当前版本保存。

`optics_get_scene` 读取场景与版本；`optics_trace_scene` 只预览；`optics_save_scene` 保存场景；`optics_apply_design` 可以把光路与指定标量参数一起原子保存。写入都要求当前版本。网页“复制给 Codex / MCP”生成指令，需粘贴到 Codex 发送；网页不会代你向 Codex 发消息。更新插件后，若工具列表仍为 15 个，请刷新 MCP 连接以载入 24 个工具。

## 内置 OpenAI 聊天

在 Codex 中可使用已连接的 OpenAI Platform 安全密钥设置流程，确认创建目标和本地保存位置。已有环境变量 `OPENAI_API_KEY` 也可复用。程序仅从服务进程环境，或明确指定 `--config` 所在目录的 `.env.local` 读取此变量。密钥只由 Python 服务使用，不返回浏览器、项目导出或 MCP。不要把密钥提交到 Git；`.env` 和 `.env.*` 已忽略。

没有密钥时聊天显示“尚未配置”，发送按钮禁用。聊天连接使用 [Responses API](https://developers.openai.com/api/docs/guides/function-calling)，默认 `gpt-5.4-mini`；可通过配置 `ai_model` 或环境变量 `OPTICS_WORKBENCH_MODEL` 选择兼容 Responses 函数调用的模型。配置信息仅表示已找到密钥，真实权限和额度在首次调用时确认；ChatGPT 登录与 API 使用配置是不同入口。

发送时，当前原型的标量参数、场景、已保存的配色预算和本面板最近 12 条对话发送到 OpenAI。原始资料、知识库正文、项目名称、项目备注、服务配置中的本机路径和整库不自动发送；已保存配色预算中的自填来源/说明也属于该预算，发送前请检查。请求使用 `store:false`；这项设置不等于对服务商其他数据处理政策的保证。

模型只能读取草稿、改指定元件、替换场景、改预算参数、编辑完整配色预算或预览光线及白点/亮度预算。修改先暂存在内存，经过同一套本地校验；模型完成回复后，按请求开始的版本一次保存。网络失败、不完整回复或并发版本冲突不会提交草稿。工具不能执行代码、选择文件、打开原生模型或访问模型指定的 URL。一个服务进程同时处理一个内置聊天请求。

AI 输出仍需检查：近轴光扇与条件预算是起算，真实像差、效率、均匀性、膜系、偏振和公差需要 LightTools / Zemax 或实测验证。参数原型导出包含可视化场景，旧版未保存场景的原型会从标量参数生成默认示意；默认查看不写入数据库。

## 验证范围

自动测试覆盖模拟 Responses 多轮工具调用、事务保存、失败回滚、上下文范围及并发冲突。模拟测试不会访问真实 API，不能证明密钥权限、模型额度或线上调用成功。浏览器与真实 stdio MCP 可独立验证，无需模型 API。
