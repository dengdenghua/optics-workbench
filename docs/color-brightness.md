# 配色与亮度计算口径

实现位于 `optics_workbench/color.py`。本模块与标量效率预算、光路场景分别编辑，只有显式输入才参与计算；保存使用同一原型版本事务。

各源 `Y=lm`，`X=xY/y`，`Z=(1−x−y)Y/y`。组内先加XYZ，再归一化得到组色坐标；不能按lm直接平均xy。默认输入口径是单颗给定工况的CW量；数量、电流修正、温度修正、前段效率均为显式条件。输入为输出光学W时，乘提供的光谱lm/W；泵浦W时乘指定lm/泵浦W，两者不能混用。光谱光效不可由色坐标唯一推导。

按归一化组XYZ求线性方程得到目标白点各组Y比例 `f_i`。负解表示目标在可实现三角形外，自动求解拒绝该输入；退化/过度病态矩阵也拒绝。时序模式按 `white_lm=available_deg / Σ[f_i/(CW_lm_i/360)]`，`angle_i=360·white_lm·f_i/CW_lm_i` 分配，同色组所有源共用角度。消隐只通过可用角度扣一次。同时模式用 `white_lm=min(CW_lm_i/f_i)` 得到0–1调光比例，不强加RGB占空比和为1。手动模式可核对指定角度/调光，实际白点另行报告。

标为全周期已平均的输入在手动核对时不再次乘时序；重新分配时须补对应CW输入，自动求解拒绝把平均量逆推为CW。电功率应是相同工况与时间口径的单颗电功率，不根据经验WPE反推。缺失或光学W大于电学W时不输出可信电效率；只有输出光学W和同工况电学W齐全，才给源级电光差值热量，泵浦W不充当输出光学W。该差值不包含整机电子学、散热器或所有光路吸收。

屏幕预测光通量 `lm=white_lm·downstream_efficiency`；平均照度 `lx=lm/area_m²`；给定观察方向的屏幕亮度估算 `cd/m²=lm·screen_gain/(π·area_m²)`。后段效率在此为不改变RGB谱形的共用标量，有逐色选择性损失应放入逐色条件并重新求白点。面积、屏幕增益、测量网格与工况未确认时不能当实测亮度。不存在本模块通用的ANSI/CVIA换算倍率。该光通量、屏幕增益和面积关系参考 [TI DLP 显示亮度应用说明](https://www.ti.com/lit/an/dlpa068b/dlpa068b.pdf)，不代表任意屏幕、任意观察方向都Lambertian。

u′v′转换使用 `u′=4x/(−2x+12y+3)`，`v′=9y/(−2x+12y+3)`，参考 [CIE定义](https://cie.co.at/eilvterm/17-23-073)。分别在xy/u′v′平面计算基色三角形面积比以及与参考三角形的交集覆盖；面积比可大于100%，交集覆盖上限100%，均非色容积或色准。参考基色来自 [ICC P3注册表](https://registry.color.org/rgb-registry/dcip3) 与 [ICC BT.709注册表](https://registry.color.org/rgb-registry/bt709)。二维示意只画三角形，不冒充采样光谱轨迹。
